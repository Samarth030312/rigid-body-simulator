- MATLAB launches.
- MATLAB version recorded.
- Required toolboxes identified.
- Repository path is valid.

- rotation matrices;
- orthogonality;
- determinant;
- vector operations;
- transforms.

- known rigid-body transformations;
- known manipulator configurations;
- four-bar closure.

- Newton equation;
- Euler equation;
- cube inertia;
- gravity.

## Level 4 — Numerical integration

- timestep behaviour;
- convergence;
- solver comparison where implemented.

## Level 5 — Applications

- dice;
- 3R;
- four-bar.

## Level 6 — Visualization

- geometry;
- frames;
- trajectories;
- dashboards.

## Level 7 — GUI

- controls;
- input validation;
- simulation execution;
- reset;
- visualization.

the supplied demonstrations.
