## Toolbox Policy

Start with base MATLAB.

No additional toolbox is to be introduced merely because a feature sounds convenient.

A toolbox dependency must have:

1. a demonstrated engineering requirement;
2. installation/license verification;
3. documentation;
4. a validation reason.

## Known Required Capabilities

The project requires MATLAB capabilities for:

- numerical linear algebra;
- 3D graphics;
- numerical integration;
- application GUI development.
